# 🩺 A Study on Various Types of Skin Diseases

## 📌 Overview

This project presents an **AI/ML-based approach for the classification of different types of skin diseases from images**. A trained deep learning model is used to analyze input skin images and predict the corresponding disease category.

The repository contains the project source code, trained model, output images, project report, and presentation.

> **Note:** This project is developed for educational and research purposes and is not intended to replace professional medical diagnosis.

## 🎯 Objectives

* Study different types of skin diseases.
* Analyze skin images using Artificial Intelligence and Machine Learning.
* Develop a deep learning-based image classification model.
* Predict the disease category from an input skin image.
* Test the trained model using sample images.
* Display and analyze prediction results.

## 🧠 Model

The trained model is stored in:

`skin_model.h5`

The model is used to process an input skin image and generate a predicted class based on the categories used during training.

## ⚙️ Working Process

```text
Input Skin Image
       ↓
Image Preprocessing
       ↓
Feature Extraction
       ↓
Trained Deep Learning Model
       ↓
Disease Classification
       ↓
Prediction Result
```

### How It Works

1. A skin image is provided as input.
2. The image is preprocessed according to the model requirements.
3. The processed image is passed to the trained deep learning model.
4. The model analyzes the image features.
5. The model predicts the corresponding disease category.
6. The prediction result is displayed to the user.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Data-With-Jayesh/A-Study-on-Various-Type-of-Skin.git
cd A-Study-on-Various-Type-of-Skin
```

### 2. Install Required Libraries


If a `requirements.txt` file is not available, install the libraries required by the source code.

The trained model is available as:
